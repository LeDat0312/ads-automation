File supervisor config chuẩn đã được tạo: ads-automation.conf

Cài đặt trên VPS:

```bash
cd ~/ads-automation

# 1. Backup config cũ (nếu cần)
sudo cp /etc/supervisor/conf.d/ads-automation.conf /etc/supervisor/conf.d/ads-automation.conf.backup

# 2. Copy file config mới (nếu đã upload file ads-automation.conf lên VPS)
sudo cp ads-automation.conf /etc/supervisor/conf.d/ads-automation.conf

# Hoặc tạo file trực tiếp:
sudo nano /etc/supervisor/conf.d/ads-automation.conf
# Copy nội dung từ file ads-automation.conf và paste vào

# 3. Kiểm tra syntax config
sudo supervisorctl reread

# 4. Update và restart services
sudo supervisorctl update
sudo supervisorctl restart ads-automation
sudo supervisorctl restart ads-worker

# 5. Kiểm tra status
sleep 3
sudo supervisorctl status

# 6. Kiểm tra logs
sudo tail -f /var/log/ads-automation.log
```

Nội dung file config:

```ini
[program:ads-automation]
command=/home/adsuser/ads-automation/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 2
directory=/home/adsuser/ads-automation
user=adsuser
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/ads-automation.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=5
environment=PATH="/home/adsuser/ads-automation/venv/bin"

[program:ads-worker]
command=/home/adsuser/ads-automation/venv/bin/python -m app.workers.telegram_worker
directory=/home/adsuser/ads-automation
user=adsuser
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/ads-worker.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=5
environment=PATH="/home/adsuser/ads-automation/venv/bin"
```
