## Lệnh pull code:

```bash
cd /home/adsuser/ads-automation && git stash && git pull origin main && python3 -m py_compile app/api/routes/dashboard.py && sudo supervisorctl restart all && sudo supervisorctl status
```

## Kiểm tra logs sau khi pull:

```bash
# Xem logs đầy đủ (không grep để thấy tất cả lỗi)
sudo supervisorctl tail -100 ads-automation-api

# Hoặc xem logs real-time
sudo supervisorctl tail -f ads-automation-api
```

## Sau khi pull:
- Truy cập: `https://updatemetaads.site/dashboard/`
- Nếu vẫn lỗi 500, trang sẽ hiển thị thông báo lỗi chi tiết
- Kiểm tra logs để xem error message cụ thể

## Nếu vẫn lỗi:
Gửi output của lệnh `sudo supervisorctl tail -100 ads-automation-api` để tôi có thể xem lỗi cụ thể.
