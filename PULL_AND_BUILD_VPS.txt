========================================
LỆNH PULL VÀ BUILD LẠI TRÊN VPS
========================================

1. SSH vào VPS:
   ssh adsuser@your-vps-ip

2. Chạy script tự động (khuyến nghị):
   cd ~/ads-automation
   chmod +x PULL_AND_BUILD_VPS.sh
   ./PULL_AND_BUILD_VPS.sh

3. HOẶC chạy từng lệnh thủ công:

   # Dừng services
   sudo supervisorctl stop ads-automation
   sudo supervisorctl stop ads-worker
   
   # Kill process trên port 8000 (nếu cần)
   sudo lsof -ti:8000 | xargs sudo kill -9
   
   # Pull code mới
   cd ~/ads-automation
   git pull origin main
   
   # Build frontend
   cd ~/ads-automation/frontend
   npm install  # (chỉ cần chạy lần đầu hoặc khi có package mới)
   npm run build
   
   # Set ownership cho Nginx
   sudo chown -R www-data:www-data dist
   sudo chmod -R 755 dist
   
   # Reload Nginx
   sudo systemctl reload nginx
   
   # Restart services
   sudo supervisorctl reread
   sudo supervisorctl update
   sudo supervisorctl restart ads-automation
   sudo supervisorctl restart ads-worker
   
   # Kiểm tra status
   sudo supervisorctl status
   
   # Xem logs
   sudo tail -f /var/log/ads-automation.log

========================================
LƯU Ý:
========================================
- Script PULL_AND_BUILD_VPS.sh sẽ tự động làm tất cả các bước trên
- Nếu gặp lỗi permission, chạy: sudo chown -R adsuser:adsuser ~/ads-automation
- Nếu npm build lỗi, kiểm tra: node --version (cần >= 16)
- Nếu port 8000 vẫn bị chiếm, chạy: sudo netstat -tlnp | grep 8000
