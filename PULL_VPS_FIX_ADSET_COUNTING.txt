# Hướng dẫn Pull Code Mới Về VPS - Fix Adset Counting

## Cách 1: Sử dụng script tự động (Khuyến nghị)

```bash
cd ~/ads-automation
chmod +x PULL_VPS_FIX_ADSET_COUNTING.sh
./PULL_VPS_FIX_ADSET_COUNTING.sh
```

## Cách 2: Thực hiện thủ công từng bước

```bash
# 1. Dừng service và kill process trên port 8000
sudo lsof -ti:8000 | xargs sudo kill -9 2>/dev/null
sudo supervisorctl stop ads-automation
sudo supervisorctl stop ads-worker
sleep 2

# 2. Pull code mới từ GitHub
cd ~/ads-automation
git pull origin main

# 3. Build frontend (nếu có thay đổi)
cd frontend
npm install  # Chỉ cần chạy nếu chưa có node_modules
npm run build
sudo chown -R www-data:www-data dist
sudo chmod -R 755 dist
cd ..

# 4. Restart services
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl restart ads-automation
sudo supervisorctl restart ads-worker

# 5. Kiểm tra status
sleep 5
sudo supervisorctl status
sudo tail -20 /var/log/ads-automation.log
```
