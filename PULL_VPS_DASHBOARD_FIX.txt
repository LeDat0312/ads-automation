# Code để pull và fix Dashboard trên VPS

## Vấn đề:
- URL `/dashboard/` không khớp với router prefix `/api/dashboard/`
- Internal Server Error khi truy cập `/dashboard/`

## Giải pháp:
Đã thêm redirect từ `/dashboard/` sang `/api/dashboard/` trong `main.py`

## Lệnh pull code:

```bash
cd /home/adsuser/ads-automation && git stash && git pull origin main && python3 -m py_compile app/main.py && sudo supervisorctl restart all && sudo supervisorctl status
```

## Kiểm tra logs nếu vẫn lỗi:

```bash
# Xem logs
sudo supervisorctl tail -100 ads-automation-api

# Kiểm tra import
cd /home/adsuser/ads-automation
python3 -c "from app.main import app; print('OK')"

# Kiểm tra routes
python3 -c "
from app.main import app
routes = [r.path for r in app.routes if 'dashboard' in r.path]
for r in routes:
    print(r)
"
```

## Sau khi pull:
- Truy cập: `https://updatemetaads.site/dashboard/` (sẽ redirect đến `/api/dashboard/`)
- Hoặc truy cập trực tiếp: `https://updatemetaads.site/api/dashboard/`
