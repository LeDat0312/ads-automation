# Code để pull và fix Dashboard trên VPS

## Vấn đề:
- URL `/dashboard/` hiển thị "Internal Server Error"
- Router prefix là `/api/dashboard/` nhưng URL truy cập là `/dashboard/`

## Giải pháp:
1. Đã thêm redirect từ `/dashboard/` sang `/api/dashboard/` trong `main.py`
2. Cần kiểm tra logs để xem lỗi cụ thể

## Lệnh pull code:

```bash
cd /home/adsuser/ads-automation && git stash && git pull origin main && python3 -m py_compile app/main.py app/api/routes/dashboard.py && sudo supervisorctl restart all && sudo supervisorctl status
```

## Kiểm tra logs nếu vẫn lỗi:

```bash
# Xem logs chi tiết
sudo supervisorctl tail -200 ads-automation-api | grep -A 10 -B 10 "Error\|Exception\|Traceback"

# Hoặc xem toàn bộ logs
sudo supervisorctl tail -200 ads-automation-api

# Kiểm tra import
cd /home/adsuser/ads-automation
python3 -c "
try:
    from app.main import app
    from app.api.routes.dashboard import router
    print('✅ Import OK')
except Exception as e:
    print(f'❌ Lỗi: {e}')
    import traceback
    traceback.print_exc()
"

# Kiểm tra routes
python3 -c "
from app.main import app
routes = [r.path for r in app.routes if 'dashboard' in r.path]
print('Routes có chứa dashboard:')
for r in routes:
    print(f'  - {r}')
"
```

## Sau khi pull:
- Truy cập: `https://updatemetaads.site/dashboard/` (sẽ redirect đến `/api/dashboard/`)
- Hoặc truy cập trực tiếp: `https://updatemetaads.site/api/dashboard/`

## Nếu vẫn lỗi:
Gửi output của lệnh kiểm tra logs để tôi có thể sửa lỗi cụ thể.
