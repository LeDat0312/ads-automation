# VPS Deployment - Quick Start Guide

## You encountered these 3 errors:

```bash
./force_pull.sh                              # ❌ Permission denied
python -m migrations.add_facebook_accounts_table  # ❌ No module named migrations.add_facebook_accounts_table
sudo supervisorctl restart backend            # ❌ backend: ERROR (no such process)
```

---

## ✅ SOLUTION (Copy-Paste These Commands on VPS)

### Option A: Automatic Fix (RECOMMENDED)

```bash
cd /home/adsuser/ads-automation

# Pull latest code (includes fix scripts)
git fetch origin main
git reset --hard origin/main

# Fix permissions & run quick fix
chmod +x VPS_QUICK_FIX_ERRORS.sh
./VPS_QUICK_FIX_ERRORS.sh
```

That's it! The script will:
- ✅ Fix all script permissions
- ✅ Find your supervisor service name automatically
- ✅ Run the migration
- ✅ Restart the backend

---

### Option B: Full Deployment (Clean Reset)

cd /home/adsuser/ads-automation

chmod +x VPS_DEPLOY_FACEBOOK_ACCOUNTS.sh

## Verify Deployment

After running either script:

```bash
# 1. Check service is running
sudo supervisorctl status

# Expected: SERVICE_NAME    RUNNING   pid 12345, uptime 0:00:30

# 2. Test health endpoint
curl http://localhost:8000/health

# Expected: {"status":"healthy"}

# 3. Test new API (should return 401 - needs auth)
curl -I http://localhost:8000/api/facebook-accounts

# Expected: HTTP/1.1 401 Unauthorized
```
