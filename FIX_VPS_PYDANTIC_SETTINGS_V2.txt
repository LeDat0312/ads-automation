Vấn đề: pydantic-settings đã được cài vào user site-packages nhưng supervisor đang dùng Python environment khác.

Chạy các lệnh sau để kiểm tra và sửa:

```bash
cd ~/ads-automation

# 1. Kiểm tra supervisor config
sudo cat /etc/supervisor/conf.d/ads-automation.conf

# 2. Kiểm tra Python path mà supervisor đang dùng
# Lấy từ command trong supervisor config
# Ví dụ: command=/var/www/ads-automation/venv/bin/uvicorn
# => Python path là: /var/www/ads-automation/venv

# 3. Tạo venv mới nếu chưa có (hoặc cài vào venv hiện có)
# Nếu venv không tồn tại:
python3 -m venv /var/www/ads-automation/venv
source /var/www/ads-automation/venv/bin/activate
pip install pydantic-settings==2.1.0
pip install -r requirements.txt  # Cài tất cả dependencies

# 4. Hoặc cài vào system Python (nếu supervisor dùng system Python)
sudo python3 -m pip install pydantic-settings==2.1.0

# 5. Restart service
sudo supervisorctl restart ads-automation
sleep 5
sudo supervisorctl status

# 6. Kiểm tra logs
sudo tail -f /var/log/ads-automation.log
```

Hoặc chạy script tự động:

```bash
cd ~/ads-automation
chmod +x FIX_VPS_PYDANTIC_SETTINGS_V2.sh
bash FIX_VPS_PYDANTIC_SETTINGS_V2.sh
```
