# 🚀 React/Vite Frontend - Quick Start Guide

## Cài đặt & Chạy

```bash
cd frontend
npm install
npm run dev
```

Dashboard sẽ chạy tại: **http://localhost:3000**

## Deploy Production

### Build:
```bash
npm run build
```

### Copy to server:
```bash
sudo cp -r dist/* /var/www/ads-dashboard/
```

Xem chi tiết trong `frontend/README.md` và file DEPLOYMENT_GUIDE.md gốc.
