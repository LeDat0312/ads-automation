# Static Files Directory

Thư mục này chứa các file tĩnh như favicon, images, etc.

## Favicon

Để thêm favicon cho website:

1. Đặt file favicon.png vào thư mục này (`app/static/favicon.png`)
2. File sẽ tự động được serve tại `/static/favicon.png`
3. Website sẽ tự động sử dụng favicon này

### Yêu cầu:
- Tên file: `favicon.png`
- Kích thước khuyến nghị: 512x512px hoặc 256x256px
- Format: PNG (có thể dùng ICO, nhưng PNG được khuyến nghị)
